# Jan Bauer's personal page

A new rebuilded personal page of Jan Bauer using **Astro 7 static site with zero React**, deployed on **Cloudflare Workers** static assets.

## Stack

- **Astro 5** — fully static output, built-in i18n (`/en`, `/cz`), `<ClientRouter />` view transitions
- **Tailwind CSS 4** (Vite plugin) — theme tokens in CSS, class-based dark mode
- **Vanilla three.js** — the floating `</>` background (no react-three-fiber), one `InstancedMesh`, persisted across navigations via `transition:persist`
- **Cloudflare Workers** — static assets + a tiny Worker that only runs for `/` and redirects by `Accept-Language` (`cs` → `/cz`, else `/en`)

All copy lives in `src/i18n/messages/{en,cz}.json`; page content is data-driven from `src/config/*` (experiences, education, skills, socials, nav). Site URL, contact email and social links come from `.env`.

## Development

```bash
cp .env.example .env   # adjust values if needed
npm install
npm run dev            # http://localhost:4321
```

## Deploy

```bash
npx wrangler login     # once (OAuth — no tokens stored in the repo)
npm run deploy         # astro build + wrangler deploy
```

After the first deploy, wrangler prints the real `*.workers.dev` URL — put it into `PUBLIC_SITE_URL` in `.env` and redeploy so canonical/OG/sitemap URLs match. When you attach a custom domain later (Cloudflare dashboard → Workers → Custom Domains), update `PUBLIC_SITE_URL` again.

For headless/CI deploys, set `CLOUDFLARE_API_TOKEN` (+ `CLOUDFLARE_ACCOUNT_ID`) instead of `wrangler login` — see `.env.example`.

`npm run preview` builds and serves the production bundle through `wrangler dev` (exercises the real Worker + asset routing, including the `/` language redirect).

## Notes

- `.env` values are **baked into the HTML at build time** (public config, not secrets); changing them requires rebuild + redeploy. Cloudflare credentials are real secrets — they stay in `.env`/environment and are never committed or rendered.
- `public/fonts/source-code-pro-subset.typeface.json` is generated by `npm run subset-font` (subsets the original 553 KB three.js font to the 3 glyphs `<`, `/`, `>`).
- `public/matcaps/*.png` is the matcap texture the old site fetched from a CDN at runtime — now self-hosted.
- Theme choice persists in `localStorage` (`COLOR_SCHEME`); default is dark.
